## 源码修复

- **高影响数据完整性问题**：原生数据库初始化用 INSERT OR REPLACE 重建系统清单，在外键 ON DELETE CASCADE 下会删除已有任务；已用原始代码行为复现。改为 INSERT OR IGNORE，并直接引用真实数据库初始化模块测试两次启动后任务仍存在。
- **环境识别错误**：原代码手动判断的 Tauri 全局标识不可靠。现在使用官方 isTauri；Mac 读写进入原生 SQLite，网页使用 IndexedDB。数据与待上传队列在同一存储提交中保存。
- **权限与脚本执行面**：原桌面 CSP 为 null，且授予未使用的 opener 权限。现在限制脚本/资源来源，移除 opener 插件与权限；原生 HTTP 只访问固定 HTTPS API 主机，禁用重定向，不向 JS 返回会话令牌。新增单实例保护，减少并发进程写入风险。
- **隐私日志**：删除任务详情和清单名称的调试输出；公网服务不记录密码、令牌或任务正文。
- **HTTP 兼容性**：清单 ID 的 randomUUID 调用在非安全 HTTP 环境中报错；增加兼容处理。
- **既有 SQL**：抽查全部仓储查询，业务参数使用 rusqlite 绑定参数；未发现将待办文本拼接为 SQL 的路径。
- **既有 UI**：未发现 eval、动态 Function 或 dangerouslySetInnerHTML 的任务内容执行路径。待办文本由 React 文本节点呈现。

## 新增服务的边界

- 单用户；公开注册关闭。密码使用 Argon2id 哈希，服务端只保存随机会话令牌的 SHA256；每设备独立、可撤销、30 天有效的服务端会话。此版本使用可即时撤销的 opaque session，不使用无法即时撤销的纯 JWT。
- 网页使用 __Host- 前缀的 Secure/HttpOnly/SameSite=Strict Cookie；API 也校验会话，所有 Cookie 写操作校验 Origin。原生令牌进入 macOS Keychain。
- 登录并发与失败次数限制；请求体 2 MiB、每批最多 100 个操作、字段白名单及标识符限制；客户端主动控制上传批次字节数，服务端限制拉取响应大小。
- 永久删除标记不会被普通旧编辑复活。幂等 operation_id、服务端递增游标和混合逻辑时钟用于重试、分页及按修改时间合并。
- 导入检查记录结构及字段，拒绝原型字段；退出清理本地缓存，修改密码撤销全部旧会话。
- 服务仅绑定 127.0.0.1，由 HTTPS 反代访问；私密配置目录和数据库限制本机文件权限。无附件上传、远程脚本执行或公开管理接口。

## 警告及限制

当前跨平台 Cargo.lock 仍包含 Linux GTK 路径的 glib（RUSTSEC-2024-0429，unsound）、glib/gtk 宏依赖 proc-macro-error（RUSTSEC-2024-0370，unmaintained），以及单实例插件 Linux D-Bus 路径中的 zbus_names/zvariant/zvariant_derive（unmaintained）。它们按依赖的平台限制不属于本次 Mac 构建目标；CI 会额外检查实际 Mac 目标依赖树，若进入构建则阻止打包。它们也不在独立服务端依赖中；完整扫描报告保留这些警告，未静默忽略。若后续制作 Linux 桌面包，必须重新处理对应风险。

这不是对所有依赖源代码的逐行证明，也不能保证未来不会发现漏洞；没有进行第三方渗透测试、形式化验证或安卓审计。当前结果表示在所记录版本和检查范围内修复了已发现问题，并通过了所列测试。
Mac 运行、离线数据与原生窗口交互最终仍需在用户真机验收；CI 编译与启动检查不等于完整真机功能验收。

## 回归验证

- 同步核心：旧离线修改晚到、不相关字段合并、过期 UI 快照不回写未编辑字段、终止删除、重复事件、原型字段、远端逻辑计数和导入校验。
- Rust 服务：按修改时间取新、幂等重试、删除防复活、非法批次回滚、匿名/跨来源拒绝、改密撤销会话。
- SQLite：保存后重新打开数据库、失败写入不破坏原数据、真实初始化重复执行不删除任务。
- 双浏览器：同一密码登录、任务/清单/标签同步、离线写入及重连、刷新持久化、完成状态传播、退出后界面与 API 访问限制。

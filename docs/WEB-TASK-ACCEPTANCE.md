# DIDA 浏览器任务交互验收

日期：2026-11-04。范围：网页与共享 React 组件；macOS 专项 review 和打包等待用户完成浏览器验收。

## 行为约定

- 单击中间栏任务行即可修改标题，失焦保存。Enter 将当前标题和下一条空任务一起保存，并在下方聚焦新任务；“无标题”是占位提示，不写入标题。
- 标题为空时再按 Backspace 删除空任务（移入垃圾桶）。有描述或子任务的任务不会因空标题被删除。中文输入法确认不会触发续建。
- 中间栏只展示根任务。第二行优先显示描述，没有描述时显示子任务标题串；摘要单行省略，完整内容在详情查看。
- 详情描述随输入增高，没有内部滚动条。首次从纯文本转为检查事项时，非空行按顺序拆分成子任务并清空原文本；空行忽略。已有检查事项后的描述独立保存，切换视图不会再把描述转成待办。整个首次转换通过离线事务保存，超长段落等失败保留原始描述及原有子任务。
- 详情模式中，独立描述显示在上方区域，下方留一行间距后展示待办文本；后续修改描述和待办文本分别保存。新增回归覆盖：首次转换后补充多行描述、切换视图后描述保持独立、间距不少于一行、详情中同时修改描述和待办文本、切回后没有额外生成描述待办。
- 检查事项/详情为双向展示切换：转为待办后提示“详情”，再次点击显示可编辑的多行文本框，再点击“检查事项”恢复复选框。纯切换保留原子任务 ID、日期、完成状态和层级，不删除重建。文本模式中编辑、添加、移除行通过一次事务保存；模式保存在当前会话的 UI 状态中，刷新后已有待办默认显示检查事项列表。
- 标签放在子任务下方。子任务悬停、点击编辑或键盘聚焦时显示闹钟和删除按钮；日期弹窗支持日期、提醒和重复设置，Esc 只关闭此弹窗。
- 网页标题、登录页名称及图标采用 DIDA。macOS 名称及发布流程留待浏览器验收通过后处理。

## 用户手动验收

1. 在所有任务及收集箱中单击标题编辑；连续 Enter 创建任务并输入，删除到空后再 Backspace；刷新检查内容和顺序。
2. 验证描述或子任务标题摘要在窄列及长文本下保持两行，详情保留完整文本。
3. 编辑多行描述，检查输入区域延展；悬停检查事项按钮查看阴影和提示，转换后核对各行和已有子任务。
4. 给子任务设置、修改和清除截止日期；悬停或点击后删除，验证刷新及多端同步结果。
5. 浏览器通过后明确反馈，再进入 macOS review 和打包流程。真实 Mac、真实多端和离线重连仍需专项验收。

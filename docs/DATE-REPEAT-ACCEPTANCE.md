# 日期菜单与重复任务验收

> 历史验收：本文记录对应阶段的行为和测试结果，“尚未打包/未实现”等表述仅描述当时状态。当前功能以 [WEB-MACOS.md](WEB-MACOS.md) 和 [TODO.md](../TODO.md) 为准，后续安装包见 [RELEASES.md](RELEASES.md)。

日期：2026-11-04。范围：浏览器端及重复生成所需的同步协议兼容扩展；本轮不 review 或打包 macOS。

## 已实现

- 第二栏任务右键菜单的日期行保留今天、明天、下周、自定义，删除下个月。中文提示通过自有浮层即时显示，键盘聚焦也可见，不使用原生 title 延迟。下周快捷按钮保留原有“7 天后”语义。
- 自定义入口接通共享日期面板：月历翻页、日期、具体时间、提醒、重复、清除、取消、确定。修改先保留在面板草稿，最终确定统一保存；取消不写入。清除同时移除日期、提醒、重复设置。菜单随内容尺寸调整位置，内部滚动不会误关弹窗。
- 重复包括不重复、每天、每周、每月、每季度、每年、周一至周五；按周/月/年的预设回显具体日期。自定义按天/周/月/年，间隔 1–999，按周可选多个星期且至少选择一个；取消自定义修改会恢复已应用的规则。
- 完成当前任务时保留当前已完成记录，并创建未完成的下一期，复制标题、描述、清单、标签、优先级、提醒、子任务树及关系；检查项重置为未完成，日期按日历偏移保留各自当地时间。浏览器离线完成时也立即本地保存，并一起进入持久化待上传队列。
- 下一期按原计划推算：提前完成仍从原截止日向后；逾期完成跳过过期计划，生成完成时间之后的首个计划日期，不批量补历史任务。月末 31 日遇短月取月末，后续仍回到 31 日；每年 2 月 29 日非闰年取 2 月 28 日，闰年回到 2 月 29 日。规则固定保存时的 IANA 时区及当地时刻，夏令时缺失时刻向后顺延，当地时刻在后续恢复。
- 两端生成同一期使用确定 ID。取消完成不会删除已生成下一期，再次完成不会重置或重复创建。软删/永久删的下一期不会因迟到生成复活；回收站任务完成不会生成新期。

## 同步兼容扩展

新增可选 Operation.initialize 与 Field.initial，旧操作缺省为 false，已有 JSON 状态不需要数据库表迁移。生成副本使用初始化字段；真实编辑优先于初始化，无论设备时钟或消息到达顺序如何。正常编辑之间继续按原时钟合并，永久删除防复活保留。API 和网页需配套发布，先更新 API 再切换网页；回退网页时保留新版 API，避免旧 API 丢弃初始化优先级标记。

旧版自定义重复只保存 custom 与间隔，丢失原本“按天/周/月/年”的频率，无法可靠恢复。遇到这类规则会要求重新选择频率，未确认前不猜测日期。当前生成逻辑由新版浏览器的完成操作触发，不把旧 macOS 客户端行为当作本轮已验收。

## 明确暂缓

时间段、法定节假日和调休、农历重复不在本轮范围。周一至周五按普通星期计算，不冒充法定工作日。进程退出后的系统通知不在本轮范围；提醒沿用应用运行期间的已有检查机制。

## 用户验收

1. 右键一个任务，悬停四个日期按钮，检查中文提示及下个月已移除。
2. 自定义选择日期/时间/提醒与重复规则，取消一次、确认一次，刷新检查回显。
3. 完成重复任务，核对原记录仍已完成，下一期未完成且日期、描述、检查项正确。
4. 修改下一期后取消并再次完成原任务，确认下一期未被重置或重复创建。
5. 浏览器全部验收通过后，再进入 macOS 专项 review 与打包。

## 两栏日期按钮与截止日期排序修正

右键菜单与各处日期面板共用 `Common/DateShortcuts.tsx`：今天（太阳）、明天（日出）、下周（日历）、自定义（日历选择）四个图标及即时中文提示，避免分别维护导致按钮缺失或图标相同。日期面板中的自定义会回到当前选中日期并聚焦日历，继续选择具体日期；时间、提醒、重复和确认/取消保持原有行为。

第二栏未完成主任务按截止时间从早到晚排序，包含同日的时分；无日期放到未完成区最前面。相同截止时间保留手动顺序及稳定次序，已完成任务继续位于已完成分区，回收站保留删除历史规则。改早/改晚/清除日期均自动重排，无需刷新；刷新后结果相同，收集箱等普通清单也使用该规则。子任务仍按其原有手动顺序和完成时间排列。拖动不能覆盖日期顺序，只调整截止时间相同的任务；续建时的新编辑行仅在日期与原任务一致时保持邻接。

验证：构建、8 项同步测试、19 项重复测试、3 项子任务排序测试及新增 4 项主任务排序测试通过。`date_order_ui.py` 验证两栏四按钮与图标一致、即时提示、自定义日历聚焦、日期改早/改晚、同日时间、清除/刷新/切换收集箱后的顺序，以及子任务顺序不受影响。既有 `task_ui.py` 和 `date_repeat_ui.py` 回归通过。截图 `/tmp/dida-date-order.png`。
